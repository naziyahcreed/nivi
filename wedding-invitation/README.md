# Niveditha & Nataraj — Digital Wedding Invitation

Premium Tamil-traditional wedding invitation built with React, Vite, Tailwind CSS, and Framer Motion.

## Quick start

```bash
cd wedding-invitation
npm install
npm run dev
```

## Customize

Edit **`src/data/weddingData.js`** for names, dates, venues, gallery, RSVP WhatsApp number, music path, and optional sections (gifts, QR, video).

Add assets under **`public/`** (e.g. `music.mp3`, photos).

## Build

```bash
npm run build
npm run preview
```
